# The Ubuntu 24.04 packages that the build, the tests and the tools need. docker/Dockerfile, CI
# (.github/workflows/build_test.yml) and tools/ci_local.sh install them. Write one package per line and only full-line
# comments: the install pipelines drop the lines that start with '#' and pass every other word to apt-get.
#
# Left out on purpose:
# - Pinocchio, coal and eigenpy: docker/install_robotpkg.sh installs them from robotpkg into /opt/openrobots.
# - Boost: no Boost package is installed explicitly. Pinocchio and coal pull the Boost 1.83 libraries they link as their
#   own dependencies, and that is the only reason Boost is on the system.
# - Abseil, Protocol Buffers, ZeroMQ and googletest: Bazel builds them from the BCR. A second copy of their headers on
#   the compiler's default include path lets a target that misses a Bazel dependency compile against the wrong release
#   (tools/hooks/test_include_style.py).
# - ROS: the processes talk over ZeroMQ + Protocol Buffers and draw with Rerun (humanoid_nmpc/docs/distributed_runtime).

# Toolchain. cmake also builds blasfeo and hpipm in their repository rules (bazel/system_libs.bzl).
